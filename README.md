# Content Management System (CMS)

A PHP and MySQL-based Content Management System developed as an academic mini project.

## Project Overview

The goal of this project is to develop a web-based Content Management System that allows authorized users to manage digital content through a structured interface.

The final features, architecture, and database design will be determined according to the Software Requirements Specification (SRS).
