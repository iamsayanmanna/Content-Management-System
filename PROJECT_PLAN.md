# Content Management System (CMS) — Project Plan

## 1. Project Overview

A web-based Content Management System (CMS) for a blog website, designed to help authors create, manage, edit, delete, and publish blog posts through a simple and responsive interface.

## 2. Technology Stack

- **Frontend:** React, Vite, HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Database Administration:** phpMyAdmin
- **Development Environment:** Visual Studio Code, Node.js, npm, XAMPP
- **Version Control:** Git and GitHub

## 3. Core Features

1. Author Login
2. Author Dashboard
3. Create Posts
4. Edit Posts
5. Delete Posts
6. View Published Posts
7. Database Management
8. Simple and Responsive Design
